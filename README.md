# Shield-Up

Shield-Up is an interactive phishing-response training dashboard. Explore a simulated security incident, identify suspicious details, assess risk, choose response actions, and review prevention tips.

## Project files

- `index.html` and `index.css`: Main dashboard
- `contributors.html` and `contributors.css`: Contributors page
