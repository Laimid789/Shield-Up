# Shield-Up

Shield-Up is an interactive cybersecurity learning website focused on phishing awareness and incident response. It guides learners through a fictional school-account incident: identify suspicious message details, assess the risk, choose response actions, and review prevention habits.

## Main Pages and files

- `index.html`: Main training dashboard and site navigation
- `index.css`: Dashboard layout and styles
- `index.js`: Scenario content, scoring, response flow, timeline, and score graph
- `about.html` and `about.css`: About Shield-Up, its learning goals, and frequently asked questions
- `contributors.html` and `contributors.css`: Contributors page

## Training flow

1. **Identify:** Inspect the simulated message for phishing warning signs.
2. **Assess:** Review the potential impact of a stolen password and unfamiliar login.
3. **Respond:** Make timed choices and receive feedback about each action.
4. **Prevent:** Review practical habits such as enabling multi-factor authentication and using unique passwords.

The dashboard includes a score and incident timeline to reflect choices made during the exercise. These are learning aids, not a real security assessment.

## Run locally

Open `index.html` in a browser. The project is a static website and does not require a build step or package installation.

## Important safety note

The incident is fictional. Shield-Up does not send messages, collect credentials, connect to accounts, scan devices, or contact an IT team. Never enter a real password into a suspicious link or training scenario. For a real suspected compromise, contact your school or organization's IT/security team through a trusted channel.
